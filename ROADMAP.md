# TalkieTalkie Roadmap

This roadmap is provisional and prioritizes validating the product before choosing a complex technical stack.

## Stage 0 — Product definition
- [ ] Define target users and primary use case.
- [ ] Define “stacking” with concrete interaction examples.
- [ ] Choose the first platform.
- [ ] Decide whether launch scope is one-to-one, groups, or both.
- [ ] Establish privacy, safety, and data-retention requirements.

## Stage 1 — Interaction prototype
- [ ] Prototype conversation list and message composer.
- [ ] Prototype sending and receiving text messages.
- [ ] Prototype thumbs-up and thumbs-down reactions.
- [ ] Test message stacking/grouping with users.
- [ ] Document accessibility and notification behavior.

## Stage 2 — Sharing
- [ ] Define file-sharing flow and supported file types.
- [ ] Add upload/download progress and clear failure states.
- [ ] Apply file-size limits, malware scanning strategy, and access controls.
- [ ] Make recipients and sharing visibility explicit.

## Stage 3 — Reliable service
- [ ] Define account, identity, and contact model.
- [ ] Implement secure authentication and session management.
- [ ] Add message delivery state, retry behavior, and abuse reporting.
- [ ] Add backups, monitoring, and operational documentation.

## Stage 4 — Limited beta
- [ ] Run a private test with clear feedback channels.
- [ ] Test reliability, accessibility, privacy, and security.
- [ ] Fix high-impact issues before public release.

## Release principle

Do not describe a feature as available until it is implemented, tested, and documented. Security and privacy requirements must be designed before handling real user conversations or files.
